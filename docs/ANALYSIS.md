# 참고 게임 분석 기록

참고 대상: 「픽셀 RPG」 (운영자 wooya, 무료 테스트 중). 2026-11-05 공개된 페이지와 번들을 REA와 브라우저로 관찰했다.

## 권리와 원칙

- 그 게임의 약관은 「게임의 그림, 소리, 글, 코드의 권리는 운영자에게 있고」라고 밝힌다. 그래서 이 저장소에는 그 게임의 코드, 그림, 소리, 글을 넣지 않았다. 이름·지역·몬스터·대사·UI는 새로 만들었다.
- 구조는 관찰한 것을 따른 부분이 있다. 무엇이 같고 무엇을 바꿨는지 아래 「원작과 대조」에 적는다.
- 약관이 부정 프로그램을 금지하므로 그 서버에 봇을 붙이지 않았다. 계정은 사용자가 직접 만들었고, 관찰은 튜토리얼 첫 화면까지 사람이 보는 속도로 했다.

## 확인 방법

| 방법 | 확인한 것 | 한계 |
|---|---|---|
| `analyze_javascript_application` (REA) | 번들 2개 파싱, 부품 그래프 | 난독화로 모듈 분리 안 됨. 동적 호출은 미상 |
| 번들 정적 검색 | 메시지 이름, 방 이름, 좌표식, 입력 키 | 서버 코드는 볼 수 없어 판정 규칙은 미상 |
| 공개 JSON (지도 1벌, 인물 설명 1개) | 지도·시트 파일 구조, 마을의 크기와 지형 구성 | 파일 내용을 저장소에 넣지는 않았지만, 첫 마을을 만들 때 요약을 출력해 보았다 |
| 브라우저 관찰 | 시작·직업 선택·튜토리얼 첫 화면의 UI 구성 | 전투·보스·후반 콘텐츠는 직접 보지 못함 |

## 관찰한 사실

- 스택: Phaser 4.2.1, Colyseus 클라이언트, Preact 계열 UI + 신호, Express, Cloudflare 터널.
- 좌표: 2:1 아이소메트릭 `x=(u-v)*64, y=(u+v)*32`, 8방향 스프라이트.
- 이동: 클라이언트가 15Hz로 `move`를 보낸다. 공격은 클라이언트가 동작을 시작하고 타격 시점에 서버로 보낸다.
- 지도: JSON에 바닥 층, 꼭짓점 격자, 소품, 장식, 물체, 절반 칸 충돌 격자.
- 기능 범위 (메시지 이름 기준): 콤보·구르기·막기, 스킬 트리, 전직, 퀘스트, 일일 임무, 파티, 길드, 거래, 경매장, 우편, 창고, 강화, 분해, 낚시, 요리, 펫, 탈것, 업적, 균열, 월드 보스, 시련, 11개 이상의 던전과 보스 패턴.

## 이 게임에 넣은 것과 안 넣은 것

| 구분 | 내용 |
|---|---|
| 넣음 | 3직업, 콤보·회피·패링, 스킬 5개씩, 장비·강화·분해, 상점, 창고, 퀘스트 9개, 파티·채팅, 필드 3곳, 던전 2곳·보스 2종, 끝없는 균열과 순위 |
| 뺌 | 길드, 거래, 경매장, 우편, 일일 임무, 낚시, 요리, 펫, 탈것, 업적, 전직, 월드 보스 |

뺀 기능은 시간 문제가 아니라 범위 판단이다. 혼자 돌려도 재미있는 핵심 순환(전투 → 드롭 → 성장 → 다음 지역)을 먼저 완성했다.

## 원작과 대조 (2026-11-06)

| 항목 | 지금 상태 |
|---|---|
| 지도 파일 구조, 충돌 격자 해상도(절반 칸) | 원작과 거의 같다 |
| 조작, 이동 전송 주기, 공격 시점 | 원작과 거의 같다 |
| 직업·콤보·회피·강화·균열 같은 게임 구조 | 같은 장르의 구조를 따랐다 |
| 카메라와 좌표식 | 바꿨다. 원작은 2:1 마름모, 이 게임은 정면 3/4 (`x=u*50, y=v*27.5`) |
| 마을 | 바꿨다. 처음엔 60×60, 지형 4종, 바닥색 `#0e1a12`, 상점 자리가 원작과 겹쳤으나 78×62의 새 배치로 다시 지었다 (개울, 돌다리, 논, 돌담길, 고택, 장터) |
| 강화 비용·성공률 | 원작과 다르다. 원작의 서버 공식은 볼 수 없다 |
| 그림, 소리, 글, 이름 | 전부 새로 만들었다 |

## 알 수 없는 것

서버 판정 공식, 드롭률, 경제 수치, 보스 AI 내부, 동시 접속 처리 방식은 서버 쪽이라 볼 수 없다. 이 게임의 값은 전부 직접 정했고, 원본과 같은지 비교하지 않았다.
