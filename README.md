# 등불길

꺼져 가는 길에 다시 등불을 켜는 실시간 액션 RPG. 브라우저에서 돌아가고, 여럿이 함께할 수 있다.

코드, 그림, 소리, 글은 이 저장소에서 새로 만들었다. 참고한 게임과의 관계는 [docs/ANALYSIS.md](docs/ANALYSIS.md)에 적었다.

## 실행

Node 24 이상이 필요하다.

```bash
npm install
```

```bash
npm run build
```

```bash
npm start
```

http://localhost:2567 을 연다. 개발할 때는 `npm run dev`(서버 2567 + Vite 5173)를 쓴다.

## 내용

- 직업 3개: 수호자, 등불술사, 순찰자. 콤보 3타, 회피, 패링, 스킬 5개.
- 지역: 등불마루(마을), 이끼숲, 고목의 빈터(던전), 잿빛 벌판, 용광로(던전), 균열(끝없는 층).
- 보스 2종: 이끼 고목왕, 꺼진 등불지기. 바닥 경고를 보고 피하는 패턴과 체력 단계가 있다.
- 장비 드롭·희귀도·추가 능력, 강화와 분해, 상점, 창고, 퀘스트 9개, 파티(경험치 공유, 같은 던전), 채팅, 저장.
- 입은 장비가 겉모습을 바꾼다. 투구·갑옷·신발·반지·목걸이·무기마다 모델이 달라지고, 등급과 강화는 색과 빛으로 보인다. 다른 플레이어에게도 그대로 보인다.

## 구조

```
shared/    서버와 화면이 함께 쓰는 데이터와 규칙 (직업, 스킬, 몬스터, 아이템, 퀘스트, 좌표)
server/    Colyseus 방(전투·AI 판정), REST 로그인, SQLite 저장
client/    3D 무대(render3d: three.js), 글자·효과 위층(game: Phaser), Preact UI, 합성 소리
tools/     지도 생성기(genmaps), 아이콘 굽기·뼈대와 동작(bake), 블렌더 짐승·사람(blender), 그림 점검(lookdev)
tests/     서버 통합 시험, 브라우저 플레이 시험
docs/      명세와 분석 기록
```

전투는 서버가 판정한다. 이동은 화면이 먼저 움직이고 서버가 속도와 충돌을 검증한다.

## 에셋 상태 보기

개발 서버를 켜고 `/assets.html`을 연다. 배포에는 들어가지 않는다.

```bash
npx vite --port 5174
```

- 몬스터·보스: 모델 출처(블렌더 glb / 코드 모델 / 불러오기 실패), 게임 능력치, 삼각형·뼈·텍스처·파일 크기, 동작 길이. 끌어서 돌리고, 동작·확대·속도를 고르고, 예전 코드 모델과 나란히 비교한다.
- 인물: 세 직업의 처음 옷차림과 최고 장비, NPC 다섯.
- 아이콘: 아이템과 스킬 아이콘.
